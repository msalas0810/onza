# Onza — instrucciones para Claude Code

**Primer paso, siempre:** leé `DIARIO.md` (raíz) antes de escribir código: "Estado actual", "Pendientes abiertos" y las últimas entradas. Después leé `AGENTS.md`, que tiene las reglas completas de producto, seguridad, dinero y verificación, y aplican igual a Claude Code.

@AGENTS.md

## Al terminar cada sesión

Agregá una entrada nueva en `DIARIO.md` con la plantilla del archivo: fecha y hora, persona, IA y modelo, rama y commits, qué cambió, qué verificaste y qué no. Actualizá "Estado actual". No borres entradas anteriores. No escribas secretos ni afirmes que algo funciona sin haberlo comprobado.
